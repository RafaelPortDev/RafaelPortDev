# 👨🏻‍💻 Rafael Portugal

**`Tecnologia & Desenvolvimento`**

Olá! Me chamo **Rafael Portugal**, sou formado em **Análise e Desenvolvimento de Sistemas (ADS)** pela FAMINAS, em Muriaé-MG, e tenho grande interesse por tecnologia e desenvolvimento de software.

Tenho conhecimentos em **desenvolvimento Full Stack**, utilizando tecnologias como **React, JavaScript, Node.js, Python, Java e C#**, além de ferramentas voltadas para análise e visualização de dados, como **Power BI**.

Estou sempre buscando aprimorar meus conhecimentos, explorar novas tecnologias e desenvolver minhas habilidades técnicas e práticas, com o objetivo de evoluir profissionalmente e contribuir para projetos na área de **Tecnologia da Informação**.
